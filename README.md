# GPT from scratch

A hands-on project for building intuition on transformer training from randomly initialized weights, following along with Andrej Karpathy's tutorial for guidance (https://github.com/karpathy/build-nanogpt). Entirely for learning purposes! As a sanity check, a 106,368-parameter with character model with two transformer blocks completed 100 CPU updates and decreased validation loss 4.1957 to 3.0908.
